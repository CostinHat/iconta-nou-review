# Cum se transmite declarația 106 — PDF cu XML atașat sau prin mijloace electronice?

OPANAF 1292/2014, anexa 2, pct. I.3, prevede că declarația 106 **se completează cu ajutorul programului de asistență**. Pentru depunere, textul prevede **două variante**:

1. la organul fiscal competent, **în format PDF cu fișier XML atașat, pe suport CD**, însoțit de **formatul hârtie, semnat și ștampilat** conform legii; sau
2. **prin mijloace electronice de transmitere la distanță**, în conformitate cu prevederile legale în vigoare.

Nu există o variantă de completare manuală a formularului. În ambele cazuri, punctul de plecare este programul de asistență.

### Varianta 1: CD și exemplar pe hârtie

Programul de asistență generează formularul PDF cu fișierul XML atașat. Pentru depunerea fizică este nevoie de:

- **CD-ul** cu fișierul PDF care conține XML-ul;
- **exemplarul pe hârtie** al aceluiași formular, **semnat și ștampilat** potrivit legii.

Ambele se depun la organul fiscal competent din cadrul ANAF pentru administrarea societății (anexa 2, pct. I.2). În acest caz, data depunerii este data înregistrării la registratura organului fiscal (Codul de procedură fiscală, art. 103 alin. (3)).

### Varianta 2: transmitere electronică

Același PDF cu XML atașat, generat de programul de asistență, se poate transmite prin mijloace electronice de transmitere la distanță. În acest caz:

- semnătura se consideră îndeplinită prin transmiterea electronică în condițiile legii (Codul de procedură fiscală, art. 102 alin. (4) lit. b));
- data depunerii este data înregistrării pe portal, așa cum rezultă din mesajul electronic, cu condiția validării (Codul de procedură fiscală, art. 103 alin. (4));
- dacă declarația, depusă în termen, este respinsă pentru erori, o declarație validă depusă până în ultima zi a lunii termenului păstrează data inițială (art. 103 alin. (5)).

### Ce variantă alegi

Instrucțiunile permit ambele variante. Codul de procedură fiscală, art. 103 alin. (1), prevede însă că declarațiile transmise obligatoriu electronic se stabilesc prin ordin al președintelui ANAF. Societățile vizate de declarația 106 — societăți naționale, companii naționale și societăți controlate de stat — trebuie deci să verifice dacă li se aplică o astfel de obligație înainte să aleagă depunerea pe CD. Transmiterea electronică oferă și dovada datei, prin mesajul de confirmare, și semnalarea imediată a erorilor la validare.

### Verificări înainte de transmitere

1. Folosește versiunea curentă a programului de asistență pentru declarația 106.
2. Completează codul de identificare fiscală aliniat la dreapta, cu prefixul RO dacă societatea este înregistrată în scopuri de TVA (anexa 2, pct. II.1).
3. La secțiunea II, trece pentru fiecare autoritate publică centrală acționar denumirea, codul fiscal, cota de participare și dividendele distribuite (pct. II.2).
4. Validează fișierul înainte de transmitere.
5. Arhivează PDF-ul transmis și mesajul de confirmare sau exemplarul cu număr de înregistrare.

### Dacă ai transmis greșit

Declarația se corectează prin declarație rectificativă, pe același model de formular, și se transmite prin aceleași canale (anexa 2, pct. I.4).

### De reținut

- Declarația 106 se completează obligatoriu cu programul de asistență.
- Se depune pe CD, ca PDF cu XML atașat, împreună cu exemplarul pe hârtie semnat și ștampilat, sau se transmite electronic.
- Electronic, data depunerii este data validării pe portal.
- Verifică dacă societății i se aplică obligația de transmitere exclusiv electronică.
