# Formularul 214 pentru persoane juridice — se transmite obligatoriu electronic, cu programul de asistență?

**Da.** Pentru persoanele juridice, OPANAF 216/2023, anexa 2, pct. I.4.3.1, prevede: cererea 214 **„se completează cu ajutorul programului de asistență și se transmite prin mijloace electronice de transmitere la distanță"**. Anexa 6 lit. b) pct. 3 lit. b) confirmă că, pentru persoanele juridice, completarea și editarea formularului se fac cu echipament informatic. Pentru persoanele fizice, echipamentul informatic este doar o opțiune.

### Diferența dintre persoana juridică și persoana fizică

| | Persoană fizică | Persoană juridică |
|---|---|---|
| Completare | pe hârtie sau pe calculator | obligatoriu cu programul de asistență |
| Depunere | la registratură, prin poștă cu confirmare de primire sau electronic | prin mijloace electronice de transmitere la distanță |
| Temei | anexa 2, pct. I.4.2.1–I.4.2.4 | anexa 2, pct. I.4.3.1 |

Pentru persoanele fizice, data depunerii pe hârtie este data înregistrării la organul fiscal sau data predării la poștă (pct. I.4.2.3).

### Programul de asistență

Potrivit pct. I.4.4, programul de asistență este pus gratuit la dispoziție de unitățile fiscale subordonate sau poate fi descărcat de pe site-ul ANAF. Pe pagina ANAF a formularului 214 apar două variante:

- **soft A**, programul de completare;
- **soft J**, destinat contribuabililor care generează fișierul XML din aplicațiile lor informatice.

Pe aceeași pagină sunt publicate și anexa de validări și schema XSD. Înainte de depunere, verifică dacă folosești versiunea curentă a programului.

### Ce conține cererea persoanei juridice

Conținutul este același ca pentru persoana fizică:

- anul înstrăinării;
- codul de identificare fiscală, cu prefixul RO dacă firma este înregistrată în scopuri de TVA (anexa 2, pct. II.2.2);
- numărul și data hotărârii judecătorești care ține loc de contract de vânzare (pct. II.3);
- caseta de solicitare potrivită: transfer de teren agricol extravilan sau transfer de pachet de control (pct. II.4–II.5);
- datele împuternicitului, dacă este cazul (pct. II.6).

Cererea se depune însoțită de copia hotărârii judecătorești și de documentația aferentă (pct. I.2). La transmiterea electronică, pregătește aceste documente în format electronic, potrivit regulilor canalului folosit.

### Data depunerii în format electronic

Pentru declarațiile transmise electronic, Codul de procedură fiscală, art. 103 alin. (4), stabilește că data depunerii este data înregistrării pe portal, așa cum rezultă din mesajul electronic, cu condiția validării. Dacă cererea nu este validată, data depunerii devine data validării.

### Exemplu

SC Agroinvest SRL a pierdut, printr-o hotărâre care ține loc de contract de vânzare, un teren agricol extravilan cumpărat în 2022. Contabilul descarcă programul de asistență pentru formularul 214 și completează datele firmei și ale hotărârii. Apoi bifează caseta pentru transferul terenurilor agricole extravilane, generează fișierul și îl transmite electronic. Recipisa sau mesajul de confirmare se păstrează la dosar.

### De reținut

- Persoana juridică nu poate depune formularul 214 pe hârtie: îl completează cu programul de asistență și îl transmite electronic.
- Persoana fizică poate alege între hârtie și transmitere electronică.
- Programul de asistență este gratuit și se descarcă de pe site-ul ANAF.
- În format electronic, data depunerii este data validării pe portal.
