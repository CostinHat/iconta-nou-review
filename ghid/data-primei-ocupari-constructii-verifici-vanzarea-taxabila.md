# Care este data primei ocupări a unei construcții când verifici dacă vânzarea ei este taxabilă?

Data primei ocupări este data la care beneficiarul semnează procesul-verbal de recepție la terminarea lucrărilor. Pentru o construcție realizată în regie proprie, este data documentului pe baza căruia construcția este înregistrată în contabilitate ca activ corporal fix. De la această dată se numără termenul care decide dacă vânzarea este a unei construcții noi, taxabilă, sau a uneia vechi, scutită.

Codul fiscal consideră nouă construcția livrată cel târziu până la 31 decembrie a anului următor anului primei ocupări sau utilizări. După acest termen, livrarea este scutită, cu posibilitatea de a opta pentru taxare.

## Temeiul legal

::: ghid-temei
„livrarea unei construcții noi sau a unei părți din aceasta înseamnă livrarea efectuată cel târziu până la data de 31 decembrie a anului următor anului primei ocupări ori utilizări a construcției sau a unei părți a acesteia, după caz, în urma transformării;"
— Codul fiscal (Legea 227/2015), art. 292 alin. (2) lit. f) pct. 3 (sursă: [Legea nr. 227/2015 privind Codul fiscal](https://legislatie.just.ro/Public/DetaliiDocument/171282))
:::

::: ghid-temei
„Se consideră a fi data primei ocupări, în cazul unei construcții sau al unei părți din construcție care nu a suferit transformări de natura celor prevăzute la art. 292 alin. (2) lit. f) pct. 4 din Codul fiscal, data semnării de către beneficiar a procesului-verbal de recepție definitivă a construcției sau a unei părți din construcție. Prin proces-verbal de recepție definitivă se înțelege procesul-verbal de recepție la terminarea lucrărilor, încheiat conform legislației în vigoare. În cazul unei construcții realizate în regie proprie, data primei ocupări este data documentului pe baza căruia construcția sau partea din construcție este înregistrată în evidențele contabile drept activ corporal fix."
— Normele metodologice (HG 1/2016), Titlul VII, pct. 55 alin. (3) (sursă: [HG nr. 1/2016 (Normele metodologice ale Codului fiscal)](https://legislatie.just.ro/Public/DetaliiDocument/174822))
„Dacă livrarea unei construcții intervine înainte de data primei ocupări, astfel cum este definită prima ocupare la alin. (3) , se consideră că are loc livrarea unei construcții noi."
— HG 1/2016, Titlul VII, pct. 55 alin. (5) (sursă: [HG nr. 1/2016 (Normele metodologice ale Codului fiscal)](https://legislatie.just.ro/Public/DetaliiDocument/174822))
:::

Ce înseamnă concret:

- **Construcție executată de un constructor:** data primei ocupări este data semnării de către beneficiar a procesului-verbal de recepție la terminarea lucrărilor. Nu contează data mutării efective, data contractului de vânzare sau data intabulării.
- **Construcție în regie proprie:** data documentului prin care construcția este înregistrată în contabilitate ca activ corporal fix (de exemplu, procesul-verbal de punere în funcțiune pe baza căruia se face trecerea din contul 231 în contul 212).
- **Livrare înainte de prima ocupare:** este întotdeauna livrarea unei construcții noi, deci taxabilă (pct. 55 alin. (5)).
- **Construcție transformată:** dacă transformarea costă cel puțin 50% din valoarea construcției după transformare (art. 292 alin. (2) lit. f) pct. 4), nu mai contează prima ocupare, ci **prima utilizare** după transformare. Aceasta este data semnării procesului-verbal de recepție a lucrărilor de transformare sau, în regie proprie, data documentului prin care se majorează valoarea construcției (pct. 55 alin. (4)).
- **Termenul:** construcția este nouă până la 31 decembrie a anului următor celui al primei ocupări sau utilizări. O livrare după această dată este scutită (art. 292 alin. (2) lit. f)), cu opțiune de taxare (art. 292 alin. (3)).

::: ghid-exemplu
SC Exemplu SRL a construit un spațiu de birouri cu un constructor. Procesul-verbal de recepție la terminarea lucrărilor a fost semnat pe 10.05.2025. Construcția rămâne nouă până la 31.12.2026.
- Vânzare pe 15.11.2026: livrarea unei construcții noi, taxabilă cu TVA 21%.
- Vânzare pe 20.02.2027: livrare scutită de TVA, dacă nu se optează pentru taxare.
:::

## Ce se greșește în practică

- Se consideră dată a primei ocupări data mutării efective sau data semnării contractului de închiriere. Norma leagă prima ocupare de procesul-verbal de recepție semnat de beneficiar.
- Se numără „2 ani" de la recepție, în loc de termenul corect: până la 31 decembrie a anului următor.
- La o clădire renovată masiv, se ignoră testul de 50% și se aplică vechea dată a primei ocupări, deși după transformare contează data primei utilizări.
- La construcțiile în regie proprie, se caută un proces-verbal cu un constructor, deși data relevantă este cea a documentului de înregistrare ca activ fix.
