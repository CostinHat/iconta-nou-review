# D010 / D020 / D070 / D700 — status metoda "structura din validator" (12.08.2026)

## D010, D020, D070 — BLOCATE: nu au validator XML deloc
Canalul oficial DUKIntegrator (`static.anaf.ro/static/10/Anaf/update5/versiuni.xml`) listeaza ~60 declaratii
cu validator XML (D017, D085, D092, D100 … D710). **D010/D020/D070 NU apar** — nu exista validator XML pentru
ele. Sunt formularele vechi de inregistrare/mentiuni fiscale, inlocuite de D700 (mediu electronic).
=> Blocaj pe LIPSA de structura XML (nu pe capacitate). Nu se forteaza.

### Structura (citita din bytecode, clasele v3)
- Radacina `declaratie700`: ~150 atribute. Identificare: cif, den, nume_decl/pren_decl/func_decl, luna, an,
  dec_inreg, data_inreg, tip_incarcare, totalPlata_A. Plus ZECI de flag-uri `Bifa_*` (Bifa_A/B/C/D/E/F/G,
  Bifa_1b..Bifa_8b, Bifa_1c13..15, Bifa_6b_inreg/anulare/abc, Bifa_nou_infiintata, Bifa_trecePM, …) care
  CONDITIONEAZA sectiuni pe operatie (inregistrare/modificare/radiere pe fiecare obligatie de vector fiscal).
- Sectiuni copil (clase v3): Caen_C, Caen_F, Contab, Domiciliu, Impozite_D, Impozite_E, Impozite_F, Sedii_G,
  Nif_atribuit, Stare61, Stare62, Lista41, Lista42, Activ1.

### BLOCAJ (de ce nu s-a construit)
1. **DUKIntegrator returneaza `cod eroare=-5` pe D700 XML standalone**, pe TOATE namespace-urile (v1-v4), cu si
   fara `-c config`, fara fisier de rezultat. Contra-proba: D230 valideaza cu aceeasi comanda (da erori de
   continut, nu -5). => D700 e declaratie **SmartPDF**; validatorul nu proceseaza XML standalone ca la
   D230/D311. Fara proba pe DUK nu se construieste/publica tax XML neverificat (regula proiectului).
2. Chiar cu validare, un D700 CU SENS cere maparea operatie reala -> flag-uri `Bifa_*` + sectiuni, care se
   citeste din ACTUL OPANAF (instructiunile formularului), NU din numele campurilor din validator. Fara act =
   ghicit -> punct de oprire.

### Ce ar debloca D700
- calea de validare a D700 SmartPDF (cum invoca DUKIntegrator D700 ne-`-5`), SAU
- actul OPANAF D700 (instructiuni camp-cu-camp: operatie -> Bifa/sectiune), pentru maparea corecta.
